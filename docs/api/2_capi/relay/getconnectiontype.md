# GetConnectionType

Returns how this player is connecting or connected to the other players: `WEBSOCKET`, `TCP` or `UDP` to a relay server, `DIRECT` peer to peer, or `INVALID` when not connecting or connected.

:::info
Direct connect is available in the C# client library from 6.2.
:::
