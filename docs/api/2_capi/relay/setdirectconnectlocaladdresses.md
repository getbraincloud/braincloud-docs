# SetDirectConnectLocalAddresses

Sets whether direct connect offers this player's local network addresses. Two players behind the same router usually need them to connect to each other directly; without them, they usually use the lobby's server.

:::info
Direct connect is available in the C# client library from 6.2.
:::

## Method Parameters

| Parameter | Description |
| --------- | ----------- |
| include | `true` to offer local network addresses. |

:::note

On by default on every platform except iOS, where using the local network may show the player a permission prompt. Turn it on for iOS only if your game already has that permission (`NSLocalNetworkUsageDescription` in its `Info.plist`).

:::
