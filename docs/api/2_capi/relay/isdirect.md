# IsDirect

Returns whether this player is connecting or connected to the other players directly, peer to peer, rather than through a relay server.

:::info
Direct connect is available in the C# client library from 6.2.
:::

## Usage

```csharp

{
    Debug.Log("This match is connected peer to peer");
}
```
